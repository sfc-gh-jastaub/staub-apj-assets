# HTML Report Skill

You produce a single, self-contained HTML document that wraps Cortex Agent
findings in a clean, branded, executive-ready layout. The output of this
skill is HTML only — no surrounding prose, no markdown.

## When to invoke

Activate this skill when the user asks to convert prior analysis, a deep
research result, or any agent output into a polished report (for emailing,
sharing, or saving as an artefact).

## Required inputs

Pull from the conversation context:

1. **Title** — derived from the user's question or the analysis topic.
2. **Audience** — assume executive (Head of Risk / CRO) unless stated.
3. **Body content** — the findings, charts, tables, and recommendations
   already produced by the agent.
4. **Date** — today's date.

If any input is missing, infer from context. Never block to ask the user.

## Output rules

- Output **valid, self-contained HTML5** — inline CSS only, no external
  assets, no JS.
- Single root `<html>` document. Must render correctly when pasted into an
  email body or saved as `.html`.
- Width capped at 720px, centered, system-font stack.
- Use the colour palette below.
- Include in this order: cover header → executive summary (≤4 sentences) →
  key findings (bulleted or numbered) → supporting detail (tables where
  helpful) → recommended next steps → footer.
- Tables: striped rows, `border-collapse: collapse`, light grey header.
- No emojis. No marketing language. Plain, factual, confident tone.

## Brand palette

| Element | Hex |
|---------|-----|
| Primary (Snowflake blue) | `#29B5E8` |
| Accent (deep navy) | `#11567F` |
| Body text | `#1F2937` |
| Subtle background | `#F4F7FA` |
| Border / dividers | `#E5E7EB` |

## Skeleton (use as the basis for every report)

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>{{TITLE}}</title>
</head>
<body style="margin:0;padding:24px;background:#F4F7FA;font-family:-apple-system,BlinkMacSystemFont,'Segoe UI',Roboto,sans-serif;color:#1F2937;">
  <div style="max-width:720px;margin:0 auto;background:#ffffff;border:1px solid #E5E7EB;border-radius:8px;overflow:hidden;">
    <div style="background:#11567F;padding:24px 28px;color:#ffffff;">
      <div style="font-size:12px;letter-spacing:.08em;text-transform:uppercase;opacity:.8;">SnowBank Risk Analytics</div>
      <h1 style="margin:6px 0 0;font-size:22px;font-weight:600;">{{TITLE}}</h1>
      <div style="font-size:13px;opacity:.85;margin-top:4px;">{{DATE}}</div>
    </div>
    <div style="padding:24px 28px;">
      <h2 style="font-size:14px;letter-spacing:.06em;text-transform:uppercase;color:#11567F;margin:0 0 8px;">Executive summary</h2>
      <p style="margin:0 0 20px;font-size:15px;line-height:1.55;">{{EXEC_SUMMARY}}</p>

      <h2 style="font-size:14px;letter-spacing:.06em;text-transform:uppercase;color:#11567F;margin:24px 0 8px;">Key findings</h2>
      {{KEY_FINDINGS_HTML}}

      <h2 style="font-size:14px;letter-spacing:.06em;text-transform:uppercase;color:#11567F;margin:24px 0 8px;">Supporting detail</h2>
      {{SUPPORTING_DETAIL_HTML}}

      <h2 style="font-size:14px;letter-spacing:.06em;text-transform:uppercase;color:#11567F;margin:24px 0 8px;">Recommended next steps</h2>
      {{NEXT_STEPS_HTML}}
    </div>
    <div style="padding:14px 28px;background:#F4F7FA;border-top:1px solid #E5E7EB;font-size:11px;color:#6B7280;">
      Generated by SnowBank Risk Agent · Snowflake Cortex · {{DATE}}
    </div>
  </div>
</body>
</html>
```

## Quality bar

- Renders identically in Gmail, Outlook, and Apple Mail.
- An exec can read the report in under 60 seconds.
- Every claim ties back to data already produced by the agent — no
  fabricated numbers.
